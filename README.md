# FitLog - Workout Library & Planner

FitLog is a modern workout tracking web app designed for fitness enthusiasts. Browse lifts, inspect workout instructions, save your favorite exercises, and manage a focused daily plan.

## 🛠️ Technologies Used
- Next.js (App Router)
- React Context API
- Tailwind CSS
- Lucide React
- React Hot Toast

## ✨ Key Features
1. **Interactive Workout Library:** Explore exercises with real-time stats (duration, calories, rating) in a responsive grid.
2. **Instant Sorting:** Sort library exercises by duration, calories, or rating via dropdown.
3. **Daily Plan Cap (5 Lifts):** Add targeted workouts to "Today's Plan" with an enforced 5-lift cap.
4. **Live Metrics Bar:** Exercises count, estimated minutes, and calories update automatically in real time.
5. **Mark as Done & Remove:** Interactive actions to check off completed lifts with instant toast notifications and LocalStorage sync.
